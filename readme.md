# 📚 BookNest - Website Peminjaman Buku Online

Selamat datang di repositori resmi **BookNest** — sebuah aplikasi peminjaman buku online yang saya kembangkan sebagai bagian dari **proyek sertifikasi BNSP** untuk bidang Web Developer. Proyek ini menggunakan **ReactJS** sebagai frontend dan **PHP Native** sebagai backend.

## 🚀 Teknologi yang Digunakan

- **Frontend:** ReactJS (Vite, JSX, Tailwind)
- **Backend:** PHP Native (tanpa framework)
- **Database:** MySQL
- **Library tambahan:** Axios, React Router, SweetAlert, dll.

## 🎯 Fitur Utama

- 🔐 Autentikasi user (login, register)
- 📚 Daftar dan detail buku
- 🛒 Sistem peminjaman dan pengembalian buku
- 📈 Dashboard Admin untuk kelola data
- 🔎 Pencarian dan filter buku
- 📄 Riwayat transaksi user
